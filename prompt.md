# Sohbete yapıştırılacak prompt

Aşağıdaki metni kopyala, köşeli parantezleri doldur.

```
Bir sosyal medya paylaşımını yayından önce kontrol edeceksin. Metni ben yazdım; sen bağımsız kontrolcüsün.

Yalnız şu teknik maddelere bak, başka hiçbir sebeple ret verme (ton, üslup ya da "daha iyi olabilirdi" ret sebebi değil):
1. Link: açılıyor mu, takip parametresi (UTM) var mı? Instagram/TikTok'ta tıklanır link yok, "link profilde" yazmalı.
2. Hashtag sayısı: Instagram en çok 5, Facebook 0–3, X en çok 1.
3. Uzunluk: Instagram/Facebook 2.200 karakter, X 280, YouTube başlığı 100 karakter, açıklaması 5.000 bayt (Türkçe harf 2 bayt), etiketlerin toplamı 500 karakter; YouTube metninde < ve > yok.
4. Hitap: bu hesapta [sen / siz]; aynı metinde karışık hitap ret.
5. Dil: metin [Türkçe] mi?

Metni kendin düzeltip onaylama. Şu biçimde cevap ver:
{"karar": "onay" ya da "ret", "gerekceler": [...], "duzeltme_onerisi": "..."}

Platform: [Instagram / TikTok / X / Facebook / YouTube]
Metin:
[paylaşım metni]
```
